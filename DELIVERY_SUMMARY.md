## 🎨 DESIGN SYSTEM COMPONENTS

### Color System
- **Primary Purple**: #7C3AED (main brand)
- **Accent Rose**: #F43F5E (CTAs)
- **Dark Background**: #0F0F23 (gaming aesthetic)
- **Light Text**: #E2E8F0 (12.5:1 contrast)
- **12 semantic colors** (success, warning, destructive, etc.)

### Typography
- **Russo One + Chakra Petch** (bold gaming headings)
- **Plus Jakarta Sans** (clean modern body)
- **JetBrains Mono** (technical text)
- **8-step size scale** (12px to 60px)

### Components
- **5 Button Variants**: primary, accent, outline, ghost, secondary
- **3 Sizes**: large, regular, small (all ≥44px for accessibility)
- **3 Card Styles**: glass, elevated, 3D float
- **Spacing Grid**: 4px base (8 scale steps)
- **7 Border Radius Options**: 6px to full
- **4 Shadow Levels**: sm, md, lg, xl + glows

### Animations
- **Stagger Reveals**: 300-400ms duration on scroll
- **3D Transforms**: 6-8 degree perspective on hover
- **Spring Easing**: cubic-bezier(0.23, 1, 0.32, 1)
- **Respects prefers-reduced-motion**: accessibility first
